## 📝 Project Overview
This project is a professional command-line calculator designed to demonstrate the bridge between mathematical logic and software development.
Unlike basic calculators, this version focuses on code robustness and user experience through advanced error handling.

## 🚀 Technical Features (As seen in the code)
* Modular Architecture: I implemented separate functions for each arithmetic operation (addition, subtraction, multiplication, and division) to ensure clean and reusable code.
* Smart Error Handling: Using try...except blocks to catch ValueError, preventing the program from crashing if the user enters non-numeric data.
* Mathematical Edge Cases: The division function includes a specific logic check to handle "Division by Zero," returning a clear error message instead of a system crash.
* Continuous Logic: Integrated a while True loop to allow multiple calculations in a single session, making it a functional tool for daily math tasks.

## 🛠️ Implementation Details
* Language: Python 3.12 (as shown in my VS Code environment).
* Development Environment: VS Code on Asus VivoBook Pro 14 OLED.
* Coding Style: Clean documentation with headers and descriptive comments.
